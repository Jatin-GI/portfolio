# Jatin Gupta — Desktop Portfolio

An interactive, desktop-OS-style personal portfolio built with **Next.js (App Router)**, **JavaScript/JSX**, **Tailwind CSS**, **Framer Motion**, **Zustand**, and **react-rnd**.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit content in:

- `src/data/profile.js`
- `src/data/projects.js`
- `src/data/experience.js`
- `src/data/skills.js`
- `src/data/social.js`

Replace:

- `public/resume.pdf` — your resume
- `public/profile-placeholder.svg` — your photo
- `public/projects/*` — project screenshots

## Features

- Full-screen desktop with icons, wallpaper, taskbar, start menu, context menu
- Draggable / resizable windows (fullscreen on mobile)
- Apps: Projects, About, Experience, Skills, Resume, Terminal, Contact
- Boot screen, keyboard shortcuts, interactive terminal
